# স্টক খাতা · BIMS

**লাইভ:** https://bkf-stock.netlify.app

ডেটা Neon-এ থাকে। শুরুর অ্যাপ পাসওয়ার্ড `bkf2026` — এটা Gmail পাসওয়ার্ড নয়।

GitHub ফাইল প্রিভিউ (শুধু ব্রাউজারে): https://htmlpreview.github.io/?https://raw.githubusercontent.com/azahar4bd/Stock/arena/01a0c907-stock/docs/index.html

বন্ধু কল্যাণ ফাউন্ডেশনের ব্রাঞ্চ আইটেম খাতা। পাসবুক, ফরম, হাজিরা খাতা ও ব্যাগের **গ্রহণ, বিতরণ ও স্থিতি** — শাখা আলাদা, অ্যাডমিন সব শাখা দেখেন।

GitHub Pages-এর প্রিভিউ ব্রাউজারেই খোলে। সেখানকার খাতা শুধু সেই ব্রাউজারে থাকে, সবার এক সার্ভার নয়। সাইটের ফাইল `docs/`-এ (`public/`-এর কপি)। নিজের কম্পিউটারে `npm start` চালালে ডেটা `data/db.json`-এ থাকে।

এটি `apps-script/Code.gs`-এর নিয়ম অনুসরণ করে বানানো স্ট্যান্ডঅলোন ওয়েব অ্যাপ। Google Sheet লাগে না। ডেটা `data/db.json`-এ থাকে।

## চালানো

```bash
npm start
```

তারপর ব্রাউজারে `http://localhost:8080` খুলুন।

## প্রবেশ

এটি **Gmail পাসওয়ার্ড নয়**। শুরুর অ্যাপ পাসওয়ার্ড: `bkf2026`

| ভূমিকা | ইমেইল | শাখা |
| --- | --- | --- |
| অ্যাডমিন | azahar4bd@gmail.com | সব শাখা |
| ইউজার | bkfgobra014@gmail.com | গোবরা B014 |

প্রথম পাতায় ইমেইল ও পাসওয়ার্ড দিয়ে লগইন। সাইন আপ চাপলে আলাদা পেজ খোলে: ব্রাঞ্চের নাম, ব্রাঞ্চ কোড, ইউজারের নাম, ইউজার আইডি, পাসওয়ার্ড ও কনফার্ম পাসওয়ার্ড। ইউজার আইডি থেকে ইমেইল নিজেই হয় (`bkf` + আইডি + কোডের সংখ্যা + `@gmail.com`) এবং সেই ইমেইলই লগইন আইডি। সাইন আপ করলে নতুন ব্রাঞ্চ খোলে।

নতুন ইউজার অ্যাডমিন প্যানেল থেকে যোগ করলে তার শুরুর পাসওয়ার্ড `bkf2026`।

## কী আছে

- স্টক রিপোর্ট টেবিল: গ্রহণ, বিতরণ, স্থিতি, অবস্থা। আইটেম ফিল্টার, প্রিন্ট ও এক্সেল।
- এন্ট্রি: তারিখ, আইটেম, চালান, গ্রহণ, বিতরণ। নিচে এন্ট্রি তালিকা।
- রিপোর্ট: প্রারম্ভিক + গ্রহণ − বিতরণ, প্রিন্ট, সইয়ের জায়গা।
- অ্যাডমিন: ব্রাঞ্চ, ইউজার, আইটেম, ব্রাঞ্চ লিংক, ব্যাকআপ।
- বাংলা / English সুইচ।
- সাধারণ ইউজার শুধু নিজের শাখার রেকর্ড দেখেন ও লেখেন।

`?branch=B027` লিংক খুললে অ্যাডমিনের ক্ষেত্রে সেই শাখা বেছে থাকে। অন্য শাখার ইউজার নিজের খাতাই দেখেন।
